// PROBLEM STATEMENT

The Modern Cyber Threat Intelligence (CTI) Crisis

Why legacy threat intelligence triage and relational databases fail against modern adversary operations
100+
Advisories Published Weekly

Security teams face an overwhelming avalanche of fragmented, unstructured threat reports (CISA alerts, Mandiant reports, FBI flash alerts, blogs). Analysts spend 80% of triage time manually reading and copy-pasting IoCs rather than defending.

10+
Aliases Per Nation-State Actor

A single nation-state adversary is assigned dozens of overlapping designations across vendors (e.g. APT29 = Cozy Bear = NOBELIUM = Midnight Blizzard = UNC2452). Disparate naming creates intelligence fragmentation and blinds analysts to unified threat campaigns.

4+
Table Recursive JOIN Latency

Traversing multi-hop infrastructure connections (ThreatActor -> USES -> Malware -> CONTACTS -> Domain) requires complex, slow recursive SQL joins. Relational models choke on high-depth link exploration and cannot scale to dynamic CTI schemas.

0%
Verifiable Provenance in Black-Box AI

Traditional machine learning models output arbitrary probability scores with zero forensic justification. SOC analysts cannot isolate critical servers or initiate blocklists without verifiable, cited evidence proving why two campaigns are related.

// EXTRACTION & NORMALIZATION

Deterministic IoC Extraction & Refanging Engine

Zero-hallucination extraction with strict RFC syntax validation and adversarial sinkhole defense
CORE EXTRACTION INNOVATIONS
✔ Deterministic Layered Regex:
Pre-compiled regex patterns extract network indicators, hashes, and ATT&CK IDs directly from unstructured text without LLM latency or hallucination.

✔ Forensic Refanging & Defanging:
Safely unmasks obfuscated strings (e.g. hxxp:// -> http://, evil[.]com -> evil.com) while preserving the original raw forensic token.

✔ RFC Syntax Validation:
Layered RFC 791 (IPv4), RFC 4291 (IPv6), and RFC 1035 (Domain) validators eliminate false positives such as software versions (2.4.5.1).

✔ Sinkhole & Public DNS Shield:
Strips known shared infrastructure (8.8.8.8, 1.1.1.1) to prevent attackers from creating artificial graph supernode bridges.

RESOLUTION MECHANISM
1. Extraction scans text against pre-indexed alias dictionaries.
2. When 'NOBELIUM' is identified, the pipeline maps it to canonical ID 'threat-actor--APT29'.
3. The database executes a MERGE on canonical ID, avoiding duplicate actor creation.
4. Merged nodes accumulate observed aliases into an array attribute for reverse search.
