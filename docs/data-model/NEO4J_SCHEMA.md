# Neo4j Threat Knowledge Graph Schema & Cypher Constraints

## 1. Node Labels and Primary Properties

| Label | Primary Key / Unique Property | Additional Indexed Properties | Description |
| :--- | :--- | :--- | :--- |
| `ThreatActor` | `id` (STIX ID: `threat-actor--...`) | `name`, `aliases`, `first_seen`, `sophistication` | Adversary group or nation-state sponsor |
| `Campaign` | `id` (STIX ID: `campaign--...`) | `name`, `first_seen`, `last_seen`, `objective` | Targeted cyber-espionage or criminal campaign |
| `Malware` | `id` (STIX ID: `malware--...`) | `name`, `is_family`, `architecture_execution_envs` | Malicious software / payload |
| `Tool` | `id` (STIX ID: `tool--...`) | `name`, `tool_version` | Dual-use or attacker utility (e.g., Mimikatz) |
| `AttackTechnique` | `id` (e.g., `T1059.001`) | `name`, `tactic`, `matrix` | MITRE ATT&CK enterprise technique |
| `Domain` | `value` (e.g., `c2-update.com`) | `tld`, `first_seen`, `is_sinkholed` | Domain name IoC |
| `IP` | `value` (e.g., `198.51.100.23`) | `version` (4/6), `asn`, `country` | IP address IoC |
| `URL` | `value` | `scheme`, `domain` | Malicious endpoint |
| `Hash` | `value` (e.g. SHA256 string) | `hash_type` (`MD5`, `SHA1`, `SHA256`) | File fingerprint |
| `CVE` | `id` (e.g., `CVE-2023-34362`) | `cvss_score`, `epss_score` | Vulnerability reference |
| `Organization` | `id` (STIX ID: `identity--...`) | `name`, `sector`, `country` | Target organization / identity |
| `Report` | `id` (STIX ID: `report--...`) | `title`, `published_at`, `source_url`, `source_tier` | Ingested source document |

---

## 2. Relationship Types & Provenance Contract

Every relationship in the graph carries mandatory provenance attributes:
- `evidence_type`: Enum (`OBSERVED`, `REPORTED`, `EXTRACTED`, `CORROBORATED`, `INFERRED`, `PREDICTED`)
- `confidence`: Float (`0.0` to `1.0`)
- `source_report_id`: String (STIX ID of originating report)
- `extracted_at`: ISO8601 Timestamp
- `weight`: Float (1.0 default, adjusted for GDS)

### Allowed Edge Matrix:
- `(:ThreatActor)-[:CONDUCTS]->(:Campaign)`
- `(:ThreatActor)-[:USES]->(:Malware | :Tool)`
- `(:ThreatActor)-[:TARGETS]->(:Organization)`
- `(:Campaign)-[:USES]->(:Malware | :Tool)`
- `(:Campaign)-[:TARGETS]->(:Organization)`
- `(:Malware)-[:CONTACTS]->(:Domain | :IP | :URL)`
- `(:Domain)-[:RESOLVES_TO]->(:IP)`
- `(:Malware)-[:HAS_HASH]->(:Hash)`
- `(:Malware)-[:EXPLOITS]->(:CVE)`
- `(:Malware)-[:USES_TECHNIQUE]->(:AttackTechnique)`
- `(:ThreatActor)-[:USES_TECHNIQUE]->(:AttackTechnique)`
- `(:Report)-[:MENTIONS]->(:ThreatActor | :Campaign | :Malware | :IP | :Domain | :CVE)`
- `(:Report)-[:SUPPORTS]->(:AnyRelationship)`
- `(:Campaign)-[:POTENTIALLY_RELATED_TO]->(:Campaign)` *(Generated by GDS/ML with evidence payload)*

## 3. Cypher Schema Constraints & Indexes

```cypher
// Uniqueness Constraints
CREATE CONSTRAINT threat_actor_id_unique IF NOT EXISTS FOR (n:ThreatActor) REQUIRE n.id IS UNIQUE;
CREATE CONSTRAINT campaign_id_unique IF NOT EXISTS FOR (n:Campaign) REQUIRE n.id IS UNIQUE;
CREATE CONSTRAINT malware_id_unique IF NOT EXISTS FOR (n:Malware) REQUIRE n.id IS UNIQUE;
CREATE CONSTRAINT attack_technique_id_unique IF NOT EXISTS FOR (n:AttackTechnique) REQUIRE n.id IS UNIQUE;
CREATE CONSTRAINT domain_value_unique IF NOT EXISTS FOR (n:Domain) REQUIRE n.value IS UNIQUE;
CREATE CONSTRAINT ip_value_unique IF NOT EXISTS FOR (n:IP) REQUIRE n.value IS UNIQUE;
CREATE CONSTRAINT hash_value_unique IF NOT EXISTS FOR (n:Hash) REQUIRE n.value IS UNIQUE;
CREATE CONSTRAINT cve_id_unique IF NOT EXISTS FOR (n:CVE) REQUIRE n.id IS UNIQUE;
CREATE CONSTRAINT report_id_unique IF NOT EXISTS FOR (n:Report) REQUIRE n.id IS UNIQUE;

// Performance Indexes
CREATE INDEX threat_actor_name_idx IF NOT EXISTS FOR (n:ThreatActor) ON (n.name);
CREATE INDEX malware_name_idx IF NOT EXISTS FOR (n:Malware) ON (n.name);
CREATE INDEX campaign_name_idx IF NOT EXISTS FOR (n:Campaign) ON (n.name);
CREATE INDEX domain_val_idx IF NOT EXISTS FOR (n:Domain) ON (n.value);
CREATE INDEX ip_val_idx IF NOT EXISTS FOR (n:IP) ON (n.value);
CREATE INDEX cve_val_idx IF NOT EXISTS FOR (n:CVE) ON (n.id);
```
